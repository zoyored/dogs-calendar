# Together Further event calendars

Public, generated calendar data for Together Further. This repository contains
JSON/ICS feeds only, plus this README and the license. Calendar maintenance,
validation and publication run separately.

## Subscribe

- All active years: https://togetherfurther.eu/api/calendar.php?year=all
- 2026: https://togetherfurther.eu/api/calendar.php?year=2026
- 2027: https://togetherfurther.eu/api/calendar.php?year=2027

These website subscription URLs remain stable when the underlying data source
changes. Country, discipline and search filters do not filter subscriptions.
Confirm event details with the organiser before registration or travel.

Machine-readable data: `data/events.json` and
`calendar/<year>/canicross-canitrail-<year>.ics` on `main`.
Generated files are updated automatically; do not edit them manually.
